# REDUX

Sitio web de **REDUX**, un proyecto de exoesqueleto mecánico para la rehabilitación y recuperación de pacientes que hayan sufrido accidentes traumatológicos.

## Sitio web

El proyecto se publica automáticamente en GitHub Pages mediante GitHub Actions.

- Sitio: https://bajalesignacio08-tech.github.io/
- Contacto: https://bajalesignacio08-tech.github.io/contacto/

## Desarrollo

Este proyecto utiliza Next.js, React, TypeScript y Tailwind CSS.

### Instalar dependencias

```bash
npm ci
```

### Ejecutar en desarrollo

```bash
npm run dev
```

### Generar la versión estática

```bash
npm run build
```

La salida estática se genera en `out/` y es la que GitHub Pages publica mediante el workflow de `.github/workflows/deploy.yml`.
